## 二、就诊时可能做的检查

| 检查项目 | 目的 | 预计费用 | 是否医保 |
|----------|------|----------|----------|
| **腰椎 MRI** | 金标准，看椎间盘和神经 | 600-1200 元 | ✅ |
| **腰椎 X 光** | 看骨骼结构、椎间隙 | 100-200 元 | ✅ |
| **腰椎 CT** | 如不能做 MRI 的替代 | 300-600 元 | ✅ |
| **肌电图 (EMG)** | 评估神经损伤程度 | 300-800 元 | ✅ |
| **体格检查** | 直腿抬高试验、肌力测试 | 挂号费内 | ✅ |

## 三、就诊时必问医生的问题

### 诊断相关
- [ ] 我的具体诊断是什么？（哪个椎间盘？压迫哪根神经？）
- [ ] 严重程度如何？（轻度/中度/重度）
- [ ] 需要做哪些检查？

### 治疗相关
- [ ] 推荐什么治疗方案？（保守/注射/手术）
- [ ] 需要吃什么药？（药名、剂量、服用时间）
- [ ] 需要卧床休息吗？多久？
- [ ] 可以工作吗？有什么限制？

### 预后相关
- [ ] 预计多久能恢复？
- [ ] 什么情况需要复诊？
- [ ] 什么情况需要立即就医？
- [ ] 复发的风险有多大？

### 生活相关
- [ ] 可以做什么运动？
- [ ] 什么动作不能做？
- [ ] 需要佩戴腰围吗？多久？
- [ ] 睡觉姿势有什么建议？
