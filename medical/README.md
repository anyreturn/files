**适用症状**：腰痛伴腿无力、腰椎间盘突出疑似

## 🏋️ 康复训练教程

**内容包括**：
- **第一阶段（第 2-4 周）**：急性期后训练
  - 踝泵运动、腹式呼吸、骨盆倾斜、直腿抬高
- **第二阶段（第 4-8 周）**：恢复期训练
  - 桥式运动、鸟狗式、平板支撑、死虫式
- **第三阶段（第 8 周后）**：强化期训练
  - 小燕飞、深蹲、游泳、快走
- **禁忌动作**：仰卧起坐、弯腰搬重物、剧烈扭转等
- **训练日志模板**：每日记录疼痛评分和训练内容

**适用症状**：腰椎间盘突出康复期

---

## ⚠️ 重要提示

1. **就医优先**：如有严重症状（足下垂、大小便异常），立即急诊
2. **专业指导**：康复训练建议在医生或康复师指导下进行
3. **循序渐进**：无痛训练，如疼痛加重立即停止
4. **长期坚持**：康复是长期过程，至少坚持 3 个月

## 🚨 危险信号（需立即就医）

| 症状 | 紧急程度 |
|------|----------|
| 腿部无力明显 | **1 周内**完成 MRI 检查 |
| 疼痛剧烈影响睡眠 | **3 天内**就医 |
| 出现足下垂 | **立即**急诊 |
| 大小便异常 | **立即**急诊（马尾综合征） |
