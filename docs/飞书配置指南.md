# 飞书群聊平台配置指南

## 📋 概述

本配置用于将 OpenClaw 多 Agent 系统集成到飞书群聊，实现多 Agent 在飞书群中的协作。

---

## 🚀 配置步骤

### 步骤 1：创建飞书应用

1. 访问 **飞书开放平台**：https://open.feishu.cn/
2. 登录飞书账号（建议使用企业账号）
3. 点击「创建应用」
4. 选择「自建应用」
5. 填写应用信息：
   - **应用名称**：OpenClaw 多 Agent
   - **应用图标**：可选
   - **应用描述**：AI 多 Agent 协作系统

---

### 步骤 2：配置应用权限

在应用管理后台，配置以下权限：

#### 2.1 机器人能力
- ✅ **机器人** - 启用机器人功能
- ✅ **自动回复** - 允许机器人回复消息
- ✅ **群聊** - 允许机器人加入群聊

#### 2.2 消息权限
- ✅ **发送消息** - 允许机器人发送消息
- ✅ **读取消息** - 允许机器人接收群消息
- ✅ **消息回调** - 配置消息事件订阅

#### 2.3 群组权限
- ✅ **群组信息读取** - 获取群基本信息
- ✅ **群成员管理** - 可选，用于管理群成员

#### 2.4 事件订阅
配置以下事件订阅：
- `im.message.receive_v1` - 接收消息事件
- `im.chat.disband_v1` - 群解散事件（可选）
- `im.chat.member.group.add_v1` - 成员入群事件（可选）

---

### 步骤 3：获取凭证

在应用管理后台获取以下凭证：

| 凭证名称 | 字段名 | 位置 |
|----------|--------|------|
| **App ID** | `appId` | 应用基本信息 → App ID |
| **App Secret** | `appSecret` | 应用基本信息 → App Secret |
| **Verification Token** | `verificationToken` | 事件订阅 → Verification Token |
| **Encrypt Key** | `encryptKey` | 事件订阅 → Encrypt Key |

---

### 步骤 4：配置请求地址

在飞书开放平台配置事件订阅的请求地址：

```
请求地址：https://你的服务器域名/feishu/webhook
```

**本地开发可用 ngrok 内网穿透**：
```bash
# 安装 ngrok
npm install -g ngrok

# 启动内网穿透（OpenClaw Gateway 默认端口 19000）
ngrok http 19000
```

---

### 步骤 5：创建配置文件

在 OpenClaw 配置目录创建飞书配置：

**文件路径**：`/home/admin/openclaw/workspace/config/feishu-channel.json`

```json
{
  "channels": {
    "feishu": {
      "enabled": true,
      "appId": "cli_xxxxxxxxxxxxx",
      "appSecret": "xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx",
      "verificationToken": "xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx",
      "encryptKey": "xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx",
      "botName": "OpenClaw 多 Agent",
      "defaultModel": "qwen3.5-plus",
      "multiAgent": {
        "enabled": true,
        "roles": ["coordinator", "developer", "researcher", "tester"],
        "maxConcurrent": 3
      },
      "messageConfig": {
        "replyToMention": true,
        "replyToKeyword": true,
        "keywords": ["@机器人", "分配任务", "总结", "进度"],
        "ignoreSelf": true
      }
    }
  }
}
```

---

### 步骤 6：安装飞书插件（如需要）

```bash
# 检查是否有飞书插件
openclaw channels list

# 如需要，安装飞书 channel 插件
npm install @openclaw/channel-feishu
```

---

### 步骤 7：启动飞书 Channel

```bash
# 方式 1：通过配置文件启动
openclaw channels start feishu

# 方式 2：命令行直接启动
openclaw channels add \
  --type feishu \
  --label "飞书多 Agent 群聊" \
  --config /home/admin/openclaw/workspace/config/feishu-channel.json
```

## 🧪 测试配置

### 测试 1：验证飞书应用

1. 在飞书开放平台点击「版本管理与发布」
2. 点击「发布」应用（或开发版本测试）
3. 在飞书中搜索你的应用机器人
4. 发送测试消息：「你好」
5. 检查是否收到回复

### 测试 2：验证多 Agent 响应

在飞书群中发送：
```
@OpenClaw 多 Agent 请帮我分配一个任务：开发一个登录功能
```

预期响应：
- **coordinator** 响应并分配任务
- **developer** 响应并提供技术方案

### 测试 3：验证关键词触发

在飞书群中发送：
```
这个 bug 怎么修复？
```

预期响应：
- **developer** 和 **tester** 自动响应

## 🔧 高级配置

### 多群聊管理

如需在多个飞书群中部署，配置如下：

```json
{
  "channels": {
    "feishu": {
      "enabled": true,
      "appId": "cli_xxxxxxxxxxxxx",
      "appSecret": "xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx",
      "groups": [
        {
          "groupId": "oc_xxxxxxxxxxxxx",
          "groupName": "技术开发群",
          "enabledAgents": ["coordinator", "developer", "tester"]
        },
        {
          "groupId": "oc_xxxxxxxxxxxxx",
          "groupName": "产品讨论群",
          "enabledAgents": ["coordinator", "researcher", "writer"]
        }
      ]
    }
  }
}
```

## ⚠️ 常见问题

### Q1: 机器人收不到消息
**检查**：
- 事件订阅是否配置正确
- 请求地址是否可访问
- 机器人是否已添加到群聊

### Q2: 机器人无法发言
**检查**：
- 应用权限是否包含「发送消息」
- 群聊设置是否允许机器人发言
- 应用是否已发布（开发版本可能有限制）

### Q3: 多 Agent 不响应
**检查**：
- 子 Agent 是否已启动
- 触发关键词是否配置正确
- 消息路由是否正常
