# 🦜 飞书多 Agent 群聊 - 快速检查清单

## ✅ 配置前准备

- [ ] 已有飞书账号（建议企业账号）
- [ ] 已安装 OpenClaw（版本 2026.2.26+）
- [ ] 网络可访问飞书开放平台（https://open.feishu.cn/）

---

## 📋 配置步骤（按顺序执行）

### 步骤 1：创建飞书应用 ⏱️ 5 分钟

- [ ] 访问 https://open.feishu.cn/
- [ ] 登录飞书账号
- [ ] 点击「创建应用」→「自建应用」
- [ ] 填写应用信息：
  - 应用名称：`OpenClaw 多 Agent`
  - 应用描述：`AI 多 Agent 协作系统`

---

### 步骤 2：配置机器人能力 ⏱️ 3 分钟

在应用管理后台：

- [ ] 点击左侧菜单「机器人」→「创建机器人」
- [ ] 填写机器人信息
- [ ] 开启「自动回复」
- [ ] 开启「群聊」权限

---

### 步骤 3：配置应用权限 ⏱️ 5 分钟

在应用管理后台「权限管理」：

- [ ] 添加权限：`机器人发送消息`
- [ ] 添加权限：`获取群组信息`
- [ ] 添加权限：`读取用户信息`
- [ ] 添加权限：`事件订阅`
- [ ] 点击「申请权限」

---

### 步骤 4：配置事件订阅 ⏱️ 5 分钟

在应用管理后台「事件订阅」：

- [ ] 开启「启用推送」
- [ ] 记录 **Verification Token**（后续填入配置文件）
- [ ] 记录 **Encrypt Key**（后续填入配置文件）
- [ ] 订阅事件：
  - [ ] `im.message.receive_v1` - 接收消息
  - [ ] `im.chat.member.group.add_v1` - 成员入群（可选）
- [ ] 配置请求地址（开发阶段可用 ngrok）：
  ```
  https://your-domain.com/feishu/webhook
  ```

---

### 步骤 5：获取应用凭证 ⏱️ 1 分钟

在应用管理后台「凭证与基础信息」：

- [ ] 记录 **App ID**（格式：`cli_xxxxxxxxxxxxx`）
- [ ] 记录 **App Secret**（点击「获取」并验证）

---

### 步骤 6：填写 OpenClaw 配置 ⏱️ 2 分钟

编辑配置文件：
```bash
vim /home/admin/openclaw/workspace/config/feishu-channel.json
```

填写以下字段：
- [ ] `appId` → 填入 App ID
- [ ] `appSecret` → 填入 App Secret
- [ ] `verificationToken` → 填入 Verification Token
- [ ] `encryptKey` → 填入 Encrypt Key

---

### 步骤 7：启动服务 ⏱️ 1 分钟

```bash
# 方式 1：使用启动脚本（推荐）
/home/admin/openclaw/workspace/scripts/start-feishu-multi-agent.sh

# 方式 2：手动启动
openclaw channels start feishu --config /home/admin/openclaw/workspace/config/feishu-channel.json
```

---

### 步骤 8：发布应用 ⏱️ 2 分钟

在飞书开放平台：

- [ ] 点击「版本管理与发布」
- [ ] 点击「发布」→ 选择发布范围（建议先选「仅企业内成员」）
- [ ] 等待审核（通常几分钟内通过）

---

### 步骤 9：添加到群聊 ⏱️ 1 分钟

- [ ] 在飞书中找到你的机器人
- [ ] 点击「添加到群聊」
- [ ] 选择一个测试群

---

### 步骤 10：测试验证 ⏱️ 2 分钟

在飞书群中发送测试消息：

- [ ] 测试基础回复：发送「你好」
- [ ] 测试@触发：发送「@OpenClaw 多 Agent 你好」
- [ ] 测试关键词：发送「帮我调研一下市场情况」
- [ ] 测试任务分配：发送「@协调员 分配一个开发任务」

---

## 🎯 完成！

全部勾选后，你的飞书多 Agent 群聊就配置完成了！

## 🔧 常用命令

```bash
# 查看活跃的 Agent
openclaw sessions list

# 查看子 Agent 状态
openclaw subagents list

# 查看飞书消息日志
openclaw channels logs feishu --limit 50

# 重启飞书 Channel
openclaw channels restart feishu

# 停止所有 Agent
openclaw subagents kill --all
```

## ⚠️ 常见问题

### 机器人收不到消息
- 检查事件订阅是否开启
- 检查请求地址是否可访问
- 检查机器人是否在群内

### 机器人无法发言
- 检查应用权限是否包含「发送消息」
- 检查应用是否已发布

### 多 Agent 不响应
- 检查子 Agent 是否已启动
- 检查触发关键词配置
